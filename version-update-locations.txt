EeveeSpotify Version Update Locations
=====================================

When bumping the version, update these 2 files:

1. control
   - Line 3: Version: X.X.X
   - Example: Version: 6.4.5

2. Sources/EeveeSpotify/Tweak.x.swift
   - static let version = "X.X.X"

Both must match for consistent versioning across the .deb package (control) and
the tweak's runtime version (Tweak.x.swift). The IPA pipelines read the version
straight from control, so they need nothing per bump.
